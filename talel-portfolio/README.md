# Talel Oueslati — Full-Stack Developer Portfolio

Retro desktop-style personal portfolio (plain HTML/CSS/JS, no build step).

## Structure
```
index.html
css/style.css
js/main.js
assets/images/   profile photo
assets/videos/   project demo videos (see assets/videos/README.md)
```

## Run locally
Open `index.html` in a browser, or: `npx serve .`

## Deploy
Push to GitHub, then Settings → Pages → Deploy from branch `main` / root.

> Videos over 100 MB need Git LFS: `git lfs track "*.mp4"`.
